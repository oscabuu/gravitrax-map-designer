# Aufgaben für dich

Alles, was nur du tun kannst, mit genauem Klickweg. Erledigtes bitte abhaken oder kurz im Chat sagen.

## Jetzt, für Etappe E0

- [ ] **Repository öffentlich stellen.** Auf GitHub das Repository `gravitrax-map-designer` öffnen → Reiter **Settings** → links **General** → ganz nach unten zur **Danger Zone** → **Change repository visibility** → **Change to public** → Bestätigung eintippen. GitHub Pages ist nur für öffentliche Repositories kostenlos.
- [ ] **GitHub Pages einschalten.** **Settings** → links **Pages** → unter **Build and deployment** bei **Source** den Eintrag **GitHub Actions** wählen. Sonst schlägt der Schritt „deploy" im Workflow fehl.
- [ ] **Branch `feat/e0-grundgeruest` nach `main` übernehmen.** Entweder sagst du mir im Chat „merge", oder du klickst auf GitHub oben den gelben Hinweis **Compare & pull request** → **Create pull request** → **Merge pull request** → **Confirm merge**. Danach baut GitHub die App und veröffentlicht sie unter https://oscabuu.github.io/gravitrax-map-designer/ (dauert zwei bis drei Minuten, Fortschritt unter dem Reiter **Actions**).

## Vor Etappe E2 (Generator)

- [ ] **Teilenamen prüfen.** Die Tabelle in `docs/konzept.md`, Abschnitt „Teile-Katalog und Teileliste", hat fünf unklare Symbole. Teile auf die Anleitungsseite legen und mir die Namen von der Verpackung oder aus dem Heft schicken.
- [ ] **Grundplatte gegenzählen.** Die 27 Felder (Reihen mit 5, 4, 5, 4, 5, 4 Feldern) sind aus der Zeichnung gezählt. Ein Blick auf die echte Platte genügt: Stimmt das, und wie liegen zwei Platten aneinander?
- [ ] **Höhen messen.** Wie viele kleine (schwarze) Höhensteine sind so hoch wie ein großer (grauer)?
- [ ] **Gefälle-Tests mit deiner Tochter.** Wie viele große Höhensteine Unterschied braucht eine kurze, eine mittlere und eine lange Schiene, damit die Kugel sicher ankommt? Wie viele Kurven hintereinander auf gleicher Höhe schafft sie?

## Später

- [ ] **Lesen und Vorlesen.** Kann deine Tochter schon lesen? Davon hängt ab, ob die Anleitung ganz ohne Text auskommen muss.
- [ ] **Name der App**, falls sie veröffentlicht wird: nicht mit „GraviTrax" beginnen, keine Logos.
